Instructions d'importation
1. Télécharger le modèle Excel

Utilisez le modèle fourni pour garantir la compatibilité des données.

Télécharger le Modèle
2. Remplir le fichier Excel

Le fichier doit contenir les colonnes suivantes :

  • SKU : Code unique (optionnel, sera généré automatiquement si vide)
  • Nom : Nom de l'article (obligatoire)
  • Catégorie : Catégorie de l'article (obligatoire)
  • Description : Description détaillée (optionnel)
  • Unité : Unité, Lot, Paquet, Boîte, Ramette, Kg, Litre (obligatoire, insensible à la casse)
  • Quantité : Quantité initiale en stock (optionnel, 0 par défaut)
  • Seuil de Commande : Seuil de réapprovisionnement (obligatoire)
Note importante : Lors de l'ajout manuel d'articles, la quantité est toujours initialisée à 0. L'importation Excel permet de définir une quantité initiale pour faciliter l'import d'un stock existant. Si vous laissez la colonne Quantité vide, elle sera automatiquement mise à 0.
Catégories valides :
  • Fournitures de bureaux et documentation
  • Produits d'hygiène et de désinfection
  • Fournitures pour le matériel informatique
  • Alimentation à usage Humaine
  • Entretien bâtiments administratifs (ou ses sous-catégories) :
    • Articles de plomberies
    • Articles électriques
    • Articles de la peinture
Note : Pour "Entretien bâtiments administratifs", vous pouvez utiliser soit la catégorie principale, soit directement l'une des sous-catégories (Articles de plomberies, Articles électriques, Articles de la peinture).
3. Importer le fichier

Sélectionnez votre fichier Excel rempli et cliquez sur "Importer".

Importer le fichier Excel
Formats acceptés : .xlsx, .xls (Excel)
